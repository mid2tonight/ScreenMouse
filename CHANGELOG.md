# Changelog

All notable changes to Screen Mouse are listed here. Download files are on the [Releases](https://github.com/mid2tonight/ScreenMouse/releases) page.

## 2.1.0 — 2026-11-26

- Images that you capture or copy can now be pasted on another computer.
- When you connect to a computer for the first time, the window is no longer hidden in the notification area. It is hidden only when the computers reconnect automatically.
- Added an error report file (`screenmouse-error.log`) that collects only error logs.
- Added **Attach error log** to **Send feedback**.

## 2.0.1 — 2026-11-21

- Paid plans are available: Standard and Professional, with add-on computers.
- Free for 1 month after you install. Join the promotion to get 1 more month free (**Settings > Promotion**).
- Updated libraries to fix security issues.
- Corrected translations and the minimum macOS version shown in the app.
